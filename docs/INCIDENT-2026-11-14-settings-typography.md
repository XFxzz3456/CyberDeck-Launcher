# 复盘：设置页字体与排版「没有标准」（2026-11-14，未发版）

## 现象

用户连续给三张设置页截图（下载 / AI 配置 / 工具组件的 Vortex 元数据），反馈：
「设置里的字体还有排版感觉有些混乱，字体大小没有个标准」。

肉眼可见的具体表现：同一张卡片里，字段标签比它下面的说明还小；中文标签被字距拉得像「散架」；
有的设置行有分隔线、有的没有；「完成后自动导入」这类开关标题和说明几乎一样大。

## 真因

1. **字号没有单一来源**。`styles.css` 18517 行里出现 24 种 `font-size`，设置页同一屏内就有
   9 / 9.5 / 10.5 / 11 / 11.5 / 12 / 12.5 / 15 八档；其中 8.5–10.5 这五档在 100% 缩放下视觉几乎不可分辨，
   却各有各的使用者。r42 曾收敛过字重与 `--fs-*` 令牌，但只覆盖了 `.switch-title/.switch-desc`，
   表单字段（`.settings-field`）与 AI/组件卡片没纳入。
2. **语义层级倒挂**。`.settings-field > span`（标签）9.5px，而 `.settings-field small` 与 `.settings-hint`（说明）
   是 11px —— **标题比正文小 1.5px**，只剩颜色在区分。Vortex 卡片同样是 dt 11px / dd 11.5px / 折叠头 12px。
3. **字体族误用**。中文标签套的是 `font-family: var(--mono)` + `letter-spacing: 1.2px`。
   等宽字体对中文没有「列对齐」收益，1.2px 字距只会把方块字拉开，这正是「看着散、乱」的直接来源。
4. **覆盖层堆积**。设置页样式被 3960 / 9547 / 11458 / 14829 等至少四处后写规则反复覆盖，
   早期定义早已失效但没人删。改样式时经常「改了这里没反应」，本质是没找到最后生效的那条。
5. **间距体系缺失**。`.settings-field` 没有分隔线、`.switch-row` 有；两者混排时段落节奏断裂。
   且相邻 `.switch-row` 是「自己 border-bottom + 后一条再加 border-top」，实际叠出 2px 双线。
6. **组件级 CSS 各自为政**。`VortexTakeoverCard.css`、`CoverCacheCard.css` 写死 9/10/11/11.5/12，
   不引用任何令牌，页面整体换了档位它们不跟。

## 走过的错误假设

- 以为「把根字号调大 / 加一条全局 `font-size`」就能统一 —— 设置页全是硬编码 px + 多层覆盖，改根无效。
- 以为直接改 `--fs-body` 的值最省事 —— 它被全站 11 处引用，改值会把模组库、下载中心一起带偏；
  最终选择「新增 `--sp-*` 五档 + `.settings-page` 作用域」，爆炸半径可控、可整块回滚。
- 以为 label 小一点显得「精致」 —— 实际造成标题弱于正文，中文 9.5px mono 直接糊成一团。
- 以为改完 CSS 就完事 —— `check-typography.mjs` 把「设置项 12px / 说明 11px」写成了硬契约，不改门禁必红；
  门禁是契约记录，改档位就得同步改契约，并顺手把「label 必须大于 hint」加进去防回归。
- 改交接卡快照时把版本行写成「对外发布 **1.8.3**」，破坏了版本门禁的正则（要求 `| 版本 | **x.y.z**` 紧邻），
  全量门禁当场抓到 `version_sync=0` —— 文档改动同样会被门禁校验，别当成「只是文字」。

## 代价 / 新约束

- 设置页新增样式**必须引用 `--sp-*`**，不再写裸 px；中文标签禁用 `--mono` + 字距，
  mono 只留给路径 / URL / 数值 / 代码。
- 「设置页排版规范」块刻意放在 `styles.css` **文件末尾**：历史覆盖层多，只有后写才能稳定压过。
  新增设置项要么引令牌，要么把规则加进这个块，否则会被旧规则吃掉。
- 门禁新增 6 条断言，以后调字号会直接红 —— 这是有意的，避免又积累出八个档位。
- 字号整体上调后**页面变长**（设置页滚动距离增加），属预期；未改任何布局宽度或控件尺寸。
- 本轮仍未升版本号 / 未构建 exe / 未打 ZIP；按交付顺序先 localhost 验收。

## 下次第一步查什么

1. 遇到「字号乱」，先跑一次同页面 `getComputedStyle(el).fontSize` 的**直方图 + 类名归因**，
   看究竟有几个档、每档是谁贡献的，别凭肉眼调。
2. 先查**语义倒挂**（标题 vs 正文 vs 说明谁大谁小），再谈数值大小；层级错比数值丑更致命。
3. 中文标签出现 mono / 大字距，一律先怀疑字体族误用（等宽对中文只有坏处）。
4. 改样式「没生效」，先 `grep` 该选择器出现的**次数与行号**，确认最后生效的是哪一条，再加 `!important` 是最后手段。
5. 改任何被门禁断言过的值，**同步改门禁期望值**，否则红的是契约不是代码。
6. 改文档里的版本行 / 横幅，记得跑 `node scripts/check-version-sync.mjs`。

## 验证留痕

- `check-typography.mjs` 从 22 条扩到 29 条，全部 PASS：`switch-title` 13 / `switch-desc` 12 /
  卡片标题 15 / label 13·500·`letter-spacing: normal`·非等宽字体 / hint 11 / hint < label。
- 全量门禁复跑 **39/39 全绿**（合计 389s 工时，含 `cargo test` 41.5s / `tsc --noEmit` / `vite build`）。
  第一次复跑时被自引入的版本行回归卡住（`SESSION-START.md §3` 版本号没紧邻加粗标记 → `version_sync=0`），
  改成 `| 版本 | **1.8.3**（…）` 后转绿 —— 文档改动同样过门禁。
- 浏览器实拍（1440×1000，Modern 暗色）：下载页标签与说明层级清楚、行间细分隔线统一；
  AI 配置页五个字段标签同号同色；工具页四个统计块的 11px 标签不再糊。
- 门禁报告：`shots/gate/report.json`。

## 遗留

- 模组库 / 下载中心 / 诊断页仍有 8–10px 的小字，未纳入本轮（用户只指设置页，避免一次改太多变量）。
- `.platform-label` 的 `text-transform: uppercase` 保留未动，英文语言包下的观感需下一次视觉复核。
- 设置页整体变长，若用户觉得「一屏信息变少」，可再考虑压缩行距（当前上下各 9px）而不是回调字号。
