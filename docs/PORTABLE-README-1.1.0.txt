CyberDeck Launcher 1.1.0 便携版 — 使用说明
================================================

一、这是什么
  CyberDeck Launcher（CDL）是 Cyberpunk 2077 的模组管理器：
  导入 / 部署 / 冲突诊断 / 加载顺序 / 下载中心 / Nexus 集成 / 存档管理 / AI 诊断，一键回滚。
  便携版 = 免安装，数据全部跟着文件夹走。

二、快速开始
  1. 把整个文件夹解压到任意「可写」目录（不要放在游戏目录里，也不要放系统盘 Program Files）。
  2. 双击 CyberDeck Launcher.exe。
  3. 首次启动：左侧「GAME LINK → 定位游戏路径」选择 Cyberpunk 2077 根目录；
     已装在游戏里的模组可以在「设置 → 游戏与路径」里一键收编进暂存区。
  4. 不清楚怎么操作就看「设置 → 帮助」：图文教程 + 常见问题，离线可查。

三、便携模式（数据在哪）
  - 状态、DPAPI 密钥、下载队列、更新备份全部保存在 exe 同级的 cyberdeck-data 文件夹里。
  - 迁移 = 整个文件夹复制走；彻底卸载 = 删掉整个文件夹。不写注册表，不碰 %APPDATA%。
  - 卸载模组只按部署清单（deployed_files）回滚，绝不推测，不会误删你的文件。

四、本版（1.1.0）能做什么

  0. 全新品牌标识
     - 左上角 Logo、启动动画、窗口/任务栏图标、网页图标统一换成新的矢量徽章
       （数据芯片 + 控制台插槽的造型），不再是两个字母拼的方块。
     - 图形只用矢量描边、颜色跟随主题 accent，六套主题下都自动变色，不会出现
       「深色主题下看不见」或「亮色主题下糊成一团」。
     - 窗口图标与 exe 内嵌图标是同一份文件，任务栏、Alt+Tab、文件属性里显示一致。

  1. Mod 更新检查与一键更新
     - 模组库工具栏「检查更新」：先查 Nexus 的「近一月有变更」清单，再按配额核对版本，
       省额度但不会漏报；配额没用完的条目会明确写「这轮没查完」而不是假装没有更新。
     - 命中后出现「全部更新」：逐个下载新版 → 先把旧版本打成 zip 备份 → 替换 →
       原来启用着的会自动重新部署。单个失败不影响其它，失败的那条原文件不动。
     - 模组详情里点「更新到 x.y」可单独更新；更新过之后同一处会出现「回滚到 x.y」。
     - 版本比较按段数值判定：1.0 与 1.0.0 视为同一版（不会误报），1.10 比 1.9 新。
     - 注意：Nexus 免费账号拿不到直连下载地址，「全部更新」需要 Premium；
       免费账号可以在详情里点「下载页」用浏览器下载，再把 ZIP 拖进启动器。

  2. AI 汉化（T5）与 AI 补丁（T6）
     - 模组详情页「部署状态」下面就有「AI 汉化…」按钮，不用再翻右键菜单；
       已汉化的模组按钮变成「重新生成」，卡片封面会显示「中·AI」徽标。
     - 工具栏「AI 工具」下拉支持批量：汉化选中 / 汉化全部，进度实时出现在任务中心。
     - 汉化产物是独立的覆盖层，**不改作者原文件**，随时可以在弹窗里撤销。
     - 需要先在「设置 → AI 配置」填好接口与模型，否则按钮会明确提示未配置。

  3. Mod 分类更准
     - 优先级：**你手动指定的分类** > Nexus 官方分类 > 文件内容 > 文件名。
     - 从 N 网安装的模组直接按官方分区归类（Weapons→武器、Clothing→服装、
       Visuals and Graphics→视觉等），不再靠文件名瞎猜。
     - 官方分区是 Miscellaneous/Environment 这类「什么都装」的分类时，只看装了哪些文件，
       不看名字；本地导入的 ZIP 才会退回文件名关键词。
     - 手动改分类：详情页下拉、右键「改分类」，或多选后批量条上的「分类」下拉。
       改过即锁定，之后任何自动归类都不会覆盖你的选择。

  4. 外观与体验
     - 赛博主题（NCPD / Arasaka / Netrunner / Militech）是碳灰分层 + 硬边 + 微光描边：
       背景 #0a0a0c、面板 #151518、卡片 #18181b，靠明度分层次，不用毛玻璃。
     - Modern 主题或开了自定义背景图时，才启用 L1/L2/L3 三级毛玻璃
       （容器 24px 模糊 / 卡片 8px / 悬浮层 32px + 大阴影）；亮色模式有专门的对比度适配。
     - 卡片文字区是不透明底板，开了背景图也不会「字糊在图上」；封面占比更大。
     - 自定义背景图：拖拽构图、滚轮缩放、暗化与模糊独立调节。
     - 通知不打扰：错误/警告提示默认约 10 秒自动消失（鼠标悬停暂停倒计时），
       同类提示合并成「标题（已发生 N 次）」，不再堆满屏幕；Toast 永远盖在活动面板之上。
     - 工具栏「补全 ▾」下拉：补全信息 / 补全封面；丢了 Nexus 引用的收编模组会先按
       文件名溯源 ModId 再回查，修掉了「明明没封面却说都有了」的误报。

  5. 稳定性
     - 每次启动核对暂存区与游戏目录的真实状态：能救回的自动救回，确认已丢的清理并提示，
       不确定的保留并给警告。
     - 长列表虚拟滚动、大图自动压缩，几百个模组也不卡。

五、常见问题
  Q: 双击没反应 / 白屏？
  A: 需要 Microsoft Edge WebView2 运行时（Win10 1803+ / Win11 通常已自带）。
     缺的话装一次「Evergreen Standalone Installer」即可。
  Q: 换电脑要重新配置吗？
  A: 把整个文件夹拷过去就行。便携版优先用同级的 cyberdeck-data；
     若目标机器上已有 %APPDATA%\com.arol.cyberdeck 状态，会按既有策略迁移进来，密钥不会丢。
  Q: 我手动往游戏目录放了模组，启动器没认？
  A: 用「设置 → 游戏与路径 → 收编」把它们登记进来，之后就能正常启停和排顺序。
  Q: 更新 Mod 之后游戏进不去？
  A: 打开该模组详情点「回滚到 x.y」，会用更新前的备份还原；也可以在
     cyberdeck-data\update-backups 里手动找到 old.zip。
  Q: 怎么看日志？
  A: cyberdeck-data\startup.log 记录每次启动的数据目录、写探测与前端挂载状态。

六、出问题怎么反馈
  把 cyberdeck-data\startup.log 和「运行诊断」页的导出结果一起发出来，
  里面有数据目录、完整性级别和各项检查的原始结论，能省掉大半来回。
