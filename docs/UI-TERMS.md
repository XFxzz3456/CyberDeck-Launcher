# UI 术语与命名规范（唯一真源）

> 2026-11-10 UI/UX 三期改造定稿。新增文案、改组件命名、写帮助文档前先查本表。
> 背景：0.9→1.4 期间「部署 / 安装 / 启用 / 撤除」「收编 / 接管」「体检 / 诊断」多套词并存，
> 同一件事在侧栏、右键菜单、抽屉、命令面板里叫法不同，玩家无法形成「去哪做这件事」的记忆。

## 1. 核心动作

| 概念 | 统一用词 | 禁止混用 | 说明 |
|---|---|---|---|
| 压缩包进入启动器 | **导入** | 安装、部署 | 只写暂存区，不碰游戏目录 |
| 模组开关状态 | **启用 / 未启用** | 部署、撤除、装载 | 界面主层唯一可见的状态词 |
| 把链接写进游戏目录 | **部署** | 安装、启用 | 仅「高级信息」与日志层可见，玩家层默认隐藏 |
| 移除游戏侧链接 | **取消部署** | 卸载、撤除 | 同上 |
| 从库中彻底删除 | **移除** | 卸载、删除 | 破坏性，必须二次确认 |

## 2. 来源与迁移

| 概念 | 统一用词 | 说明 |
|---|---|---|
| 把游戏目录里已有的 archive 纳入托管 | **收编** | 专指文件资产纳入 |
| 接管 modlist / NXM 协议 / Vortex 控制权 | **接管** | 专指控制权，不与收编混用 |
| 以 Vortex 为准重建启动器库 | **重建模组库** | 显式、破坏性、必须只读预览 + 备份 |

## 3. 检查类

| 概念 | 统一用词 | 说明 |
|---|---|---|
| AI 归因、给出修复建议 | **智能诊断** | 可能写文件，需确认 |
| 只读自检（环境 / 兼容 / Vortex 状态） | **体检** | 零写入，报告里必须标注「只读」 |
| 探测模组新版本 | **检查更新** | 只发现不自动装 |

## 4. 配置与实体

| 概念 | 统一用词 | 说明 |
|---|---|---|
| `profile` | **播放集** | AI 设置里的多套参数改叫「AI 配置」，不再用「配置」指播放集 |
| 模组实体 | **模组** | 仅模组名、文件名里允许出现 Mod / MOD |
| 本地运行的大模型 | **本地模型 / 本地运行** | 禁用「本地部署」，避免与模组部署撞词 |

## 5. 状态色语义（与 `styles/tokens.css` 一一对应）

| 语义 | 令牌 | 用途 |
|---|---|---|
| 启用 / 成功 | `--ok` + `--ok-rgb` | 状态点、成功徽章、启用态 |
| 禁用 / 中性 | `--muted-2` + `--line` | 关闭态圆点、次要标签 |
| 冲突 / 警告 | `--warn` + `--warn-rgb` | 冲突徽章、警告条 |
| 错误 / 危险 | `--danger` + `--danger-rgb` | 危险按钮、错误徽章、失败任务 |
| 信息 / 强调 | `--accent` / `--accent-text` / `--info` | 主按钮、链接、青色徽章 |

规则：填充与描边用 `--accent` 系，文字用 `--accent-text` 系；状态**不得只靠颜色**区分，必须同时有图标或文字。

## 6. 装饰性英文豁免清单

以下属品牌视觉语言，允许保留英文，但不得承载功能信息，也不得用在按钮、状态、错误提示上：

- 侧栏分区眉标：`// OPERATIONS`、`// TOOLS`、`// QUICK TASKS`、`// GAME LINK`
- 页面 eyebrow：`// MOD LIBRARY / CYBERDECK` 一类（仅装饰，标题必须是中文）
- 品牌名与专有名词：CyberDeck、Vortex、Nexus、WolvenKit、AI、NXM、REDmod

**禁止**：`RUNNING / DONE / FAILED` 这类状态词、`TASK QUEUE` 这类面板标题、
`// STAGE FIRST / DEPLOY LATER` 这类承载流程信息的英文眉标。
新增英文文本节点若不在豁免表内，`check-i18n` 应判失败。

## 7. 玩家层 / 高级层

默认界面只说「已启用 / 未启用 / 有冲突」。以下技术概念收进「高级信息」折叠区或日志层：

`staging` / `deployed_files` / `layout` / `origin` / `archive 相对路径` / `modlist.txt` / `REDmod 文件夹` / 硬链接 / `profile` 内部 id。

需要时提供「显示技术信息」开关，把认知负担留给进阶用户，而不是默认摊给所有人。
