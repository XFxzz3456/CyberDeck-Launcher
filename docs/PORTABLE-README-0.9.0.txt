CyberDeck Launcher 0.9.0 便携版 — 使用说明
================================================

一、这是什么
  CyberDeck Launcher（CDL）是 Cyberpunk 2077 的模组管理器：
  导入 / 部署 / 冲突诊断 / 加载顺序 / 下载中心 / Nexus 集成 / AI 诊断，一键回滚。
  便携版 = 免安装，数据全部跟着文件夹走。

二、快速开始
  1. 把整个文件夹解压到任意「可写」目录（不要放在游戏目录里，也不要放系统盘 Program Files）。
  2. 双击 CyberDeck Launcher.exe。
  3. 首次启动：左侧「GAME LINK → 定位游戏路径」选择 Cyberpunk 2077 根目录；
     已装在游戏里的模组可以在「设置 → 游戏与路径」里一键收编进暂存区。
  4. 不清楚怎么操作就看左侧「帮助」：6 篇图文教程 + 10 条常见问题，离线可查。

三、便携模式（数据在哪）
  - 状态、DPAPI 密钥、下载队列全部保存在 exe 同级的 cyberdeck-data 文件夹里。
  - 迁移 = 整个文件夹复制走；彻底卸载 = 删掉整个文件夹。不写注册表，不碰 %APPDATA%。
  - 卸载模组只按部署清单（deployed_files）回滚，绝不推测，不会误删你的文件。

四、本版更新要点（0.9.0，构建批次 r20–r22）

  【游戏更新到 2.5 之后】
  - 安全模式（设置 → 安全与维护）：游戏更新把模组全打崩时说一句「进安全模式」——
    它只断开部署链接、**不删除任何 Mod 文件**，然后你逐批启用排查元凶；
    排查完点「恢复原状」，按快照把启用集合和加载顺序原样装回去。
    进入和恢复都要二次确认，恢复失败时会保留快照可重试。
  - 过期插件智能扫描：自动读各模组声明的支持游戏版本，列出跟不上 2.5 的；
    读不到版本声明的只提示、不会冤枉成过期。
    （版本号按「2.21 = 2.2.1 补丁，早于 2.5」的语义比较，不会出现 21 比 5 大的误判。）

  【AI 汉化更省额度】
  - 中文译名会存进本地词表，同一个 Mod 再汉化直接复用，不再重复调用 API。
  - 设置 → AI 配置 → 可导出 / 导入词表，或打开共享开关从一个地址同步别人的译名。
  - 你自己改过的译名优先级最高，云端和 AI 都覆盖不掉。

  【配置搬家】
  - 设置 → 安全与维护 → 全局配置导出/导入：基址、模型、协议、工具路径、开关、播放集一起打包成 .json。
  - 出于安全，API Key 和加密后的密钥**不会**被打进配置包；换机后需要重新填一次。

  【本地模型】
  - AI 配置支持本地 OpenAI 兼容端点（Ollama 等），填 http://127.0.0.1:11434/v1 即可，不用联网、不花额度。

  【其他】
  - 启动动画：620ms 的品牌动画，点击或按键可立即跳过；
    设置 → 个性化 → 「启动动画」可彻底关闭（关界面动效时也会自动退化）。
  - 帮助中心：左侧「帮助」，按「教程 / 常见问题」筛选，支持搜索。
  - AI 接口协议新增 Anthropic 原生（Claude 官方 API 或原生代理），与 OpenAI 兼容协议一键切换。

五、注意事项
  - 升级覆盖：直接用新 exe 替换旧 exe 即可，cyberdeck-data 无需动。
  - 旧版 NightCity Loader 的数据目录（nightcity-data）如仍存在，首次启动会自动迁移进 cyberdeck-data。
  - 系统需要 WebView2 Runtime（Win11 自带；缺失时启动器会给出官方下载指引）。
  - 安全模式只保证「不动你的 Mod 文件」，不保证游戏能启动；游戏本体或框架版本问题它管不了。
