CyberDeck Launcher 0.8.0 便携版 — 使用说明
================================================

一、这是什么
  CyberDeck Launcher（CDL）是 Cyberpunk 2077 的模组管理器：
  导入 / 部署 / 冲突诊断 / 加载顺序 / 下载中心 / Nexus 集成 / AI 诊断，一键回滚。
  便携版 = 免安装，数据全部跟着文件夹走。

二、快速开始
  1. 把整个文件夹解压到任意「可写」目录（不要放在游戏目录里，也不要放系统盘 Program Files）。
  2. 双击 CyberDeck Launcher.exe。
  3. 首次启动：左侧「GAME LINK → 定位游戏路径」选择 Cyberpunk 2077 根目录；
     已装在游戏里的模组可以在「设置 → 游戏与路径」里一键收编进暂存区。

三、便携模式（数据在哪）
  - 状态、DPAPI 密钥、下载队列全部保存在 exe 同级的 cyberdeck-data 文件夹里。
  - 迁移 = 整个文件夹复制走；彻底卸载 = 删掉整个文件夹。不写注册表，不碰 %APPDATA%。
  - 卸载模组只按部署清单（deployed_files）回滚，绝不推测，不会误删你的文件。

四、本版更新要点（0.8.0，构建批次 r14–r18）
  - 窗口任意缩放布局不崩：侧栏底部（游戏路径 / STAGING / 版本号）固定沉底不再被挤压，
    窄窗口下模组卡片自动减列直至单列，工具条按钮自动换行不再被裁切。
  - Modern 浅色主题对比度修复：面包屑/小标签改深灰、侧栏选中项浅灰底深色字、
    主题卡选中态回归纸面白；自定义强调色自动做 WCAG 钳制，浅色下不再出现亮黄字配白底。
  - EULA 协议门重构：主界面照常渲染 + 毛玻璃遮罩，首帧不再白屏。
  - Mod 设置收进模组详情抽屉：CET / RED4ext / AudioXL 等多框架配置直接在抽屉里改，
    共用配置文件只写本模组的键，写前自动备份 .bak。
  - 界面动效（framer-motion）：设置 → 个性化 → 「界面动效」可一键关闭。

五、注意事项
  - 升级覆盖：直接用新 exe 替换旧 exe 即可，cyberdeck-data 无需动。
  - 旧版 NightCity Loader 的数据目录（nightcity-data）如仍存在，首次启动会自动迁移进 cyberdeck-data。
  - 系统需要 WebView2 Runtime（Win11 自带；缺失时启动器会给出官方下载指引）。
